# 电子狗 · STM32 四足机器人（嘉豪）

基于 **STM32F103T8**（Cortex-M3，64 KB Flash / 20 KB RAM）的电子狗 / 四足机器人控制程序。主控通过 **USART1（9600 8N1）** 接收 **ASRPRO** 语音识别模块的指令，驱动 4 路舵机完成前进、后退、转向、摇摆、跳舞、起身、坐下、打招呼、伸懒腰、睡觉等动作；同时使用 0.96 寸 OLED 显示状态，配合超声波与红外传感器避障，并通过 USART2 驱动 SYN6288 语音合成模块。

## 功能

- **语音控制**：ASRPRO 识别语音 → 串口指令 → STM32 动作状态机
- **动作**：前进、后退、左转、右转、前后摇摆、左右摇摆、跳舞、立正、起身、坐下、打招呼、伸懒腰、抬头、趴下/卧下睡觉等
- **显示**：0.96 寸 OLED（128×64），显示立正图案、开心值、体力值等
- **传感器**：超声波测距避障、红外检测
- **语音合成**：SYN6288（USART2）

## 串口指令（USART1 接收）

| 字节 | 动作 | 字节 | 动作 |
|---|---|---|---|
| `0x32` | 前进 | `0x33` | 后退 |
| `0x34` | 左转 | `0x35` | 右转 |
| `0x36` | 前后摇摆 | `0x37` | 左右摇摆 |
| `0x38` | 跳舞 | `0x39` | 立正 |
| `0x41` | 起身 | `0x61` | 坐下 |
| `0x62` | 打招呼 | `0x63` | 伸懒腰 |
| `0x64` | 抬头 | `0x65` | 趴下睡觉 |
| `0x66` | 卧下睡觉 | `0x68` | 睡觉 |

> 具体映射见 `User/main.c` 主循环。

## 编译与烧录

1. 安装 **Keil MDK5** 和 **STM32F1 器件支持包**。
2. 打开 `Project.uvprojx`，执行 **Rebuild**（F7）。
3. 通过 ST-Link / J-Link 下载到 STM32F103T8。

也可以不做编译，直接用 ST-Link Utility / FlyMcu 等工具烧录根目录的 `Project.hex`。

## 语音模块工程

`电子语音嘉豪.hd` 是 **ASRPRO** 语音模块的图形化工程（Blockly XML）。工程中配置了：

- 唤醒词：**嘉豪**
- 命令词：前进、后退、左转、右转、前后摇摆、左右摇摆、跳舞、起身等

使用该语音模块配套的图形化编程工具打开 `.hd` 工程并下载到模块即可。STM32 侧 USART1 使用 **9600 8N1**，语音模块的串口参数需与之匹配。
